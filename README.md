# Læringsspil

Læringsspil til dansk i udskolingen. Spillene kører direkte i browseren via GitHub Pages, kræver ikke login og gemmer ingen data om eleverne.

| Spil | Klassetrin | Indhold | Link |
|---|---|---|---|
| Kommajagten | 8. klasse | Punktum, komma før at/men/og/fordi/så/da, egennavne | https://kolsen14.github.io/laeringsspil/kommajagten/ |

Indholdet bygger på lærerens eget regelark og er tjekket mod Dansk Sprognævns kommaregler.
